## 关于本项目

Crystal Continuum 基于 [Crystal](https://github.com/Suprcode/Crystal) 继续开发。Crystal 是《热血传奇 2》的 C# 服务端与客户端引擎，最初由 Jamie 及贡献者创建，并由 LOMCN 社区持续发展。

上游现已进入维护模式，主要接受 Bug 修复和便于审查的小改动，不再接受较大规模的功能新增或重构。本项目因此建立独立分支，在保留原项目基础与贡献者署名的同时，继续推进超出上游维护范围的开发。相关背景可参阅[上游维护者的说明](https://github.com/Suprcode/Crystal/pull/1204#issuecomment-6638943563)。

当前目标是：**修复并完善客户端、服务端和管理工具的各方面功能，同时重制本地化体系，让文本翻译更一致、更容易维护。** 本项目不只是中文语言包：源文案保持英文，并在共享的本地化机制上同步维护简体中文资源。

本项目为独立维护的社区分支，不代表上游官方继任，也不表示获得原维护团队背书。

## 相比上游的主要改进

### 性能优化，而不只是功能增加

客户端界面与渲染性能是本分支的重点改进方向。相比上游，优化覆盖界面刷新、场景与特效绘制、图形资源管理和画面呈现，着重减少重复工作与不必要的 CPU 开销。

- **界面刷新更高效**：减少整套 UI 的重复重绘与小地图任务标记的反复创建，降低界面更新带来的主线程和纹理开销。
- **场景与特效绘制更精简**：减少地图和天气特效绘制中的重复提交与状态切换，降低渲染开销。
- **资源回收更平稳**：分摊图形资源清理工作，减少集中扫描与释放对帧时间的干扰。
- **减少无效 CPU 占用**：优化客户端等待和服务端怪物调度，避免在没有工作需要处理时持续空转。
- **改善窗口模式呈现延迟**：引入低延迟画面呈现路径，并支持窗口、无边框最大化和全屏下的等比例显示。

这些是相对上游已实施的优化方向，不代表所有设备和场景下都有固定幅度的帧率提升；实际收益取决于硬件、分辨率、场景和负载。

### 持续解决上游遗留问题

除了新增能力，本分支也着重处理影响日常体验、长期存在于原有流程中的问题。

- **显示与操作**：修复全屏切换时的卡死与卡顿、动画过程中小型或飞行怪物难以稳定选中，以及 NPC 对话长文本被截断等问题。
- **宠物与英雄**：改善宠物追击与目标争抢、英雄协助攻击及装备转移，减少战斗中的操作干扰。
- **任务与物品**：修复共享任务物品超量发放、部分物品堆叠异常，以及药剂持续时间和属性显示问题。
- **数据编辑与保存**：修复掉落编辑丢失原文件内容、怪物改名后关联数据失效等问题，并完善关服与保存失败处理。

### 重制本地化，让多语言更易维护

- 统一游戏提示与服务端管理界面的本地化方式，减少新增功能遗漏翻译的问题。
- 英文作为源语言，缺少翻译时仍能正常显示原文，也便于继续扩展其他语言。
- 持续完善简体中文覆盖，统一技能、行会等术语，补齐技能说明与管理工具文本。

### 内置脚本与任务编辑器

- 在管理工具中直接编写 NPC 脚本、事件脚本和任务定义，无需在多个外部工具间反复切换。
- 提供语法高亮、结构大纲、上下文命令提示和页面跳转，方便阅读与维护较长脚本。
- 编辑时检查脚本错误并定位源文件与行号，帮助在上线前发现问题。
- 提供可搜索的命令清单，集中查看命令用途、权限和脚本来源。

### 更直观的战斗信息与随从管理

- 悬停查看目标血量、等级及可用的怪物战斗属性。
- 新增英雄与宠物状态栏，可直接通过状态卡选中随从，方便拥挤场景中的治疗与辅助操作。
- 提供可配置的召唤物属性继承，让道士召唤物和法师宠物随主人属性成长，支持分别调整规则。

### 独立启动器与网络改进

- 独立启动器集中提供游戏启动、显示设置、资源更新和文件修复，支持更新回滚与中断恢复。
- 支持 IPv4/IPv6 双栈，扩展不同网络环境下的连接选择。
- 改善异常连接处理，减少探测流量对正常玩家接入和服务端运行的干扰。

## 分支说明

- **`master`**：面向社区、以英文为默认语言的分支，集成通用修复和选定功能，同时保留简体中文资源。
- **`dev`**：日常开发、实验功能和定制玩法分支。

以上主要改进来自当前社区分支相对上游的差异。`dev` 的额外改动不会自动全部进入 `master`。更新时请使用配套的客户端与服务端版本，涉及通信协议变更时尤其需要两端协调更新。
